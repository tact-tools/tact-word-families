# Tact Word Families

This repository contains a generator for English word-family variant data and
the generated `en_US/variants.tsv` artifact.

Generated data files are data artifacts derived from input datasets and are not
relicensed by the MIT code license. The current `en_US/variants.tsv` artifact is
derived from the Leipzig Corpora Collection English news corpus frequency list:

- Source: Leipzig Corpora Collection, `eng_news_2025_100K`
